# 15. Glossary and References — AlgoRevis

> 📖 **Terminology & Academic References**: This document defines technical terms, algorithmic methodologies, and official references utilized throughout AlgoRevis.

---

## 1. Technical Glossary

| Term | Definition in AlgoRevis Context |
|---|---|
| **Spaced Repetition** | An evidence-based learning technique that schedules review intervals at increasing durations to interrupt the forgetting curve. |
| **SuperMemo SM-2** | The algorithmic spaced repetition formula developed by Dr. Piotr Woźniak that calculates intervals and ease factors based on user performance grades (0–5). |
| **Algorithmic Archetype** | The underlying mathematical pattern governing a problem (e.g. *Two Pointers & Hash Map*, *Sliding Window*, *Monotonic Stack*, *Binary Search on Answer*) independent of cosmetic problem phrasing. |
| **Question A** | In AlgoRevis's daily challenge, Question A is the **Revision Problem** retrieved from the user's past solves scheduled for active recall. |
| **Question B** | In AlgoRevis's daily challenge, Question B is the **AI-Synthesized Variant** dynamically generated by Google Gemini to stress-test mastery of Question A's pattern. |
| **Partial Index** | A MongoDB index feature (`partialFilterExpression`) that indexes only documents meeting a specific filter, preventing duplicate `null` key collisions on optional unique fields like `phone`. |
| **Monaco Editor** | The browser-based code editor engine powering VS Code, integrated into AlgoRevis's split-pane compiler workspace. |
| **Watchdog Timer** | A safety mechanism in `codeExecutionService.js` that forcibly kills user-submitted code processes after 5,000 milliseconds to prevent denial-of-service via infinite loops. |
| **Manifest V3** | Google Chrome's modern browser extension platform standard enforcing service workers, declarative network rules, and enhanced user security. |
| **Brevo HTTPS REST API** | A cloud communication API operating over HTTPS Port 443, eliminating cloud hosting firewall blocks on legacy SMTP ports (25, 465, 587). |

## 2. Academic & Pedagogical Foundations

1. **Ebbinghaus, Hermann (1885)**. *Memory: A Contribution to Experimental Psychology*. Foundational paper detailing the mathematical decay of memory over time and the impact of structured repetition.
2. **Woźniak, Piotr (1990)**. *Optimization of Learning: The SuperMemo SM-2 Algorithm*. Mathematical formulation of adaptive review intervals based on difficulty multipliers and repetition factors.
3. **Karpicke, J. D., & Blunt, J. R. (2011)**. *Retrieval Practice Produces More Learning than Elaborative Studying with Concept Mapping*. Science, 331(6018), 772-775. Empirical validation that active recall testing dramatically outperforms passive reading.
